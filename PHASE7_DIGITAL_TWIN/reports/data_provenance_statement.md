# Data Provenance Statement — Phase 7 Digital Twin

## 1. Patient Data Source

The 917 HybridPatientStates used in Phase 7 are derived from **real patient records** from the following sources:

- **TCGA (The Cancer Genome Atlas):** 917 patients (737 training / 180 validation)
  - Source: NCI Genomic Data Commons (GDC)
  - Cancer types: LUAD (Lung Adenocarcinoma) and LUSC (Lung Squamous Cell Carcinoma)
  - Data modalities: Clinical variables + RNA-seq gene expression (STAR - Counts)
  - Platform: Illumina RNA-Seq

- **GEO cohorts (used in Phase 6 federated learning, not in Phase 7 twin construction):**
  - GSE30219, GSE50081, GSE72094, GSE31210
  - These are external validation cohorts used in Phases 2-6 but are NOT included
    in the Phase 7 Digital Twin patient states.

## 2. De-identification and Ethics

- TCGA data is publicly available through the GDC Data Portal and is already
  de-identified by the GDC. No direct identifiers (names, dates of birth,
  contact information) are present.
- TCGA patients consented to broad data sharing for cancer research.
- No IRB approval was required for this secondary analysis of publicly
  available, de-identified data.
- GEO datasets are published with open access under GEO data use policies.

## 3. Data Type Classification

| Component | Data Type | Source |
|-----------|-----------|--------|
| Clinical variables (age, sex, stage, smoking, survival) | Real patient records | TCGA GDC |
| Gene expression features (13 genes) | Real RNA-seq measurements | TCGA GDC |
| DeepSurv risk scores | AI-derived from real data | Phase 3 model trained on TCGA |
| Federated model risk scores | AI-derived from real data | Phase 6 FedAvg on 5 sites |
| ODE parameters (alpha, V_max, V0, etc.) | **Partially synthetic** | Phase 4: personalized from real gene expression via personalization function |
| Tumor trajectories (V(t), TTP) | **Fully synthetic** | Phase 4 Gompertz ODE simulation |
| Treatment response simulations | **Fully synthetic** | Phase 4 treatment-response ODE |
| Uncertainty bounds | **Derived from synthetic** | Phase 4 Monte Carlo over ODE parameter bounds |

## 4. Circularity Caveat (MANDATORY)

**The mechanistic component of the Digital Twin is partially circular.**

The ODE parameters (alpha, V_max, V0, k_immune, etc.) are personalized from
real gene expression data using the Phase 4 personalization function. However,
the tumor trajectories (V(t)), time-to-progression (TTP), and treatment
response outcomes are **simulated by the same Gompertz ODE model family**
that is used inside the Digital Twin's mechanistic simulation engine.

This means:
- Any comparison of Digital Twin-predicted TTP against "observed" TTP is
  **partially circular** — the "observed" TTP was itself generated by the
  same ODE model with the same parameters.
- The DeepSurv risk score (Phase 3) is NOT circular — it is trained on
  real survival outcomes (Overall_Survival_Time, Survival_Status) from TCGA.
- The federated model risk score (Phase 6) is also NOT circular for the
  same reason.
- Biological validation tests (Section 7D) that compare predicted TTP
  against observed TTP validate **internal consistency of the mechanistic
  module**, not real-world predictive accuracy.
- Prediction validation (C-index, calibration, IBS) that uses real
  survival outcomes (OS time, event) against DeepSurv/federated risk
  scores is **not circular** and represents genuine external validation.

**This caveat appears in the final report (Section 4) and is acknowledged
wherever synthetic labels are used in validation.**

## 6. Summary

The Phase 7 Digital Twin is built from:
1. **Real patient data** (clinical + gene expression from TCGA)
2. **AI-derived risk scores** (DeepSurv, Phase 3; federated model, Phase 6)
3. **Mechanistic simulations** (Gompertz ODE, Phase 4) — partially synthetic

The system is a Level 1 computational Digital Twin for research and
hypothesis generation. It is NOT a Level 2 (patient monitoring) or
Level 3 (clinical decision support) twin. All simulated outcomes are
biologically plausible scenarios, not clinically validated predictions.
