0. BUG DISCOVERY AND FIX — UPFRONT STATEMENT

A sign-negation bug was found in the Phase 5 C-index calculation code. The
functions compute_cindex() and bootstrap_cindex() in evaluation.py negated
risk scores before passing them to concordance_index_censored(), inverting
the C-index (0.6131 -> 0.3869). The same bug existed in the training loops of
strategy_a.py and strategy_b.py, and in the learned_weight_fusion() function
of strategy_c.py.

Fix: All instances of risk negation (-risk, -combined, -risk_val) were removed
from evaluation.py, strategy_a.py, strategy_b.py, and strategy_c.py. The
convention is now consistent across the entire codebase: higher risk = shorter
survival (standard survival analysis convention).

6. PERSONALIZATION PARITY — CLOSING THE GAP

   6a. ROOT CAUSE OF THE PERSONALIZATION GAP

   In run_phase5_integration.py (lines 364-378), validation patients receive
   dict(population_priors) with only stage-based V0 adjustments. The function
   personalize_parameters() — which maps 13 gene expression values to ODE
   parameter adjustments via z-score sigmoidal scaling — is never called for
   validation or GEO patients. This is an ENGINEERING OVERSIGHT, not a data
   limitation: the expression data and scaler are available for all cohorts.

   The 13 gene-to-parameter mappings (from personalization_function.py):
   SPP1 -> k_immune, COL1A1 -> V_max, MMP1 -> V_max, CXCL8 -> rho,
   EGLN3 -> alpha, ANGPTL4 -> V_max, MELTF -> alpha, CD109 -> alpha,
   MYEOV -> alpha, LAMC2 -> V_max, RHOV -> alpha, SORCS2 -> k_immune,
   COL22A1 -> V_max

   6b. GENE COVERAGE AUDIT

   All 13 genes have Ensembl IDs in the DeepSurv feature names and are
   present in TCGA validation expression data. GEO cohorts use gene
   symbol-indexed expression matrices (not Ensembl IDs), so the gene
   symbols are matched directly through the personalize_parameters()
   function's symbol lookup. All 13 genes are available in all cohorts.

   Coverage: 13/13 genes (100%) for TCGA val, GSE30219, GSE50081, GSE72094,

11. ROOT CAUSE ANALYSIS: WHY THE MECHANISTIC COMPONENT ADDS NOTHING
    (UPDATED WITH PERSONALIZATION INSIGHTS)

    11a. The Personalization Gap is Closed — The Null Remains

    Before personalization, the null result could be attributed to
    degenerate mechanistic features (8 unique TTP values, 12/17 features
    with zero variance). After personalization, the mechanistic features
    have genuine variance (170 unique TTP values, 167 unique alpha values),
    yet the null result persists. This rules out the personalization gap
    as the sole explanation.

    11b. Fusion Weight Still Near 1.0

    Optimal w_neural = 0.9938 (unchanged after personalization).
    The optimizer still assigns 0.62% weight to the mechanistic component.
    Even with personalized TTP carrying genuine information, the optimizer
    finds that adding it to DeepSurv does not improve concordance.

    11c. Feature Redundancy with DeepSurv

    DeepSurv's top features include Stage=IA (0.0397), Stage=IIIB (0.0178),
    MELTF (0.0198), CD109 (0.0183), MYEOV (0.0168). The mechanistic TTP is
    moderately correlated with stage (rho=0.42), and initial_volume_log is
    almost perfectly correlated with stage (rho=0.94). The mechanistic
    features are largely encoding information DeepSurv already captures:
    stage, growth rate (via MELTF/CD109/MYEOV/EGLN3), and immune status
    (via SPP1/CXCL8/SORCS2). The mechanistic model re-derives information
    from the same gene expression inputs that DeepSurv uses directly.

    11d. Strategy A Degrades — Adding Noisy Features Hurts

    Strategy A augments the 143-feature matrix with 16 mechanistic features
    and trains a new DeepSurv model. On TCGA validation, this HURTS
    (dC=-0.1233, statistically significant). The mechanistic features add
    noise without adding discriminative signal, because they are nonlinear
    transformations of features DeepSurv already has. The new model has
    more parameters to estimate with the same training data, increasing
    overfitting risk.

    11e. Strategy B's Consistency Loss Does Not Help

    Strategy B adds a rank-based mechanistic consistency penalty to the
    Cox loss. On TCGA validation, this slightly hurts (dC=-0.0287). The
    consistency loss pulls the neural model toward the mechanistic TTP
    ranking, which is less informative than the neural model's own
    learned ranking. Forcing agreement with a weaker signal degrades
    performance.

    11f. The Mechanistic Pathway is Redundant, Not Broken

    The mechanistic model (Phase 4) is a valid biological simulation tool.
    Its TTP predictions are directionally consistent with DeepSurv risk
    (rho=-0.32 after personalization). The issue is that the mechanistic
    model derives its patient-specific parameters from the SAME gene
    expression features that DeepSurv uses directly. The mechanistic
    pathway is a lossy nonlinear transformation of information DeepSurv
    already has access to — it cannot add incremental discriminative
    power because it has no independent information source.

17. LESSONS LEARNED

    17a. The Sign-Negation Bug
    concordance_index_censored() expects risk scores where higher = shorter
    survival, but the code negated them, producing 1-C instead of C. This
    went undetected because: (1) inverted values (0.3869) were plausible-
    looking, (2) double-negation in Strategy C made the hybrid appear to
    improve, (3) no regression test checked against Phase 2/3 reference
    values. Key lesson: always validate evaluation code against known
    reference values from upstream phases.

    17b. The Personalization Gap
    The personalization pipeline (Phase 4) was applied to 737 training
    patients but never to validation/GEO patients — an engineering oversight
    where the validation code path used population priors as a shortcut.
    This produced degenerate mechanistic features (8 unique TTP values)
    that made the null result ambiguous: was it the mechanistic pathway
    being uninformative, or just the missing variance? Closing the gap
    resolved this ambiguity: the null result is genuine, not artifactual.
    Key lesson: always apply the same preprocessing pipeline to all data
    splits, and test that feature variance is comparable across splits.

    17c. The Redundancy Insight
    The mechanistic model derives its patient-specific parameters from the
    SAME gene expression features that DeepSurv uses directly. It is a
    lossy nonlinear transformation of information the neural model already
    has. For mechanistic integration to add value, the mechanistic model
    must incorporate information that the neural model does NOT have access
    to — e.g., serial imaging volumes, treatment response dynamics, or
    drug pharmacokinetics. Key lesson: integration requires complementary
    information, not just complementary methodology.

EXECUTIVE SUMMARY

Phase 5 rigorously tested three neural-mechanistic integration strategies
(feature-level fusion, physics-informed loss, prediction-level fusion) against
standalone DeepSurv. A sign-negation bug in the evaluation code initially
produced inverted C-index values (0.3869 instead of 0.6131) and a spurious
"hybrid improvement." After fixing the bug and verifying against Phase 2/3
reference values (DeepSurv 0.6131, CoxPH 0.5881), the corrected results showed
no integration strategy improved on standalone DeepSurv. The initial root
cause was identified as a personalization gap: validation/GEO patients
received population-prior mechanistic parameters (8 unique TTP values vs 697
in personalized training), making the mechanistic signal near-constant and
redundant with stage information DeepSurv already captures.

To resolve whether this null result was artifactual or genuine, we closed the
personalization gap by applying the full gene-to-parameter personalization
pipeline to all validation and GEO patients (100% success rate, 1288/1288
patients). Personalized mechanistic features now carry genuine variance (170
unique TTP values, 167 unique growth rates on TCGA validation). Consistency
violations dropped from 53.3% to 35.0%, and the Spearman correlation between
DeepSurv risk and TTP became directionally consistent (rho=-0.32, p=1.6e-05).

Despite this, the null result persists: Strategy C remains identical to
DeepSurv (dC=0.0000, w_neural=0.9938), Strategy A degrades performance
(dC=-0.1233 on TCGA val), and Strategy B is slightly worse (dC=-0.0287).
The mechanistic pathway is redundant because it derives its patient-specific
parameters from the same gene expression features DeepSurv uses directly —
it is a lossy nonlinear transformation of information the neural model already
has, not a source of incremental discriminative signal.

FINAL VERDICT (quotable for thesis abstract):

"Even with the personalization gap closed — all validation and GEO patients
receiving gene-expression-personalized mechanistic parameters with genuine
feature variance — mechanistic integration provides no measurable improvement
over standalone DeepSurv (dC=0.0000, 95% CI [0.0000, 0.0000] on all cohorts),
indicating the mechanistic pathway is redundant with information DeepSurv
already captures from stage and gene expression features. DeepSurv (Phase 3)
remains the final predictive model, and the mechanistic model (Phase 4) is
retained as a complementary simulation tool for treatment scenario exploration,
not as a component that improves survival prediction."
